# 实际计算报告：三自由度 QD / RPMD / 量子子空间基线

状态：已运行的首轮数值筛查与部分独立加密检查；不是全部收敛的发表级结果。
约化单位 hbar = k_B = 1；beta 为逆温度。所有数字从 JSON 检查点生成，不是示意数据。

## 执行范围

完成 9 组定态 QD 光谱、18 组热 RPMD 计算、12 个 A 类修正预测、12 组 QD/混合波包传播及独立加密检查。
本地物理回归测试 38 项通过。初始实现的 GitHub Actions 在 Python 3.11 和 3.13 上通过；最终提交的状态以 PR 检查为准。

## B：有限时间波包概率

共同入射波包 x0=-24，位置概率标准差 sigma=4，beta=12。环境 48 beads、32 条独立样本，dt=0.03。
QD 保留横向基态，未保留热初态权重约 6.16e-6；混合方法采样有限温度状态。
下表不是热速率，也不是单能透射概率；共振在 t=75 仍有约 1.7%–2.0% 的反应区布居。

|---|---:|---:|---:|---:|---:|

B 是能量一致的平均场原型，不是严格的纠缠动力学或 iso-RPMD。共振与隧穿在这组条件下结果接近 QD，但尚未完成全部混合方法收敛扫描。
零点能组的混合概率偏低，且 32 样本的相对标准误很大（约 30%–53%）；不能据此定量判定该算法的系统误差。
零点能入射中心能量为 0.65，但高斯波包有高于 1 的动量能量尾，因此非零产物布居不违反单能散射阈值。

## 已完成的独立数值检查

- 所有散射模型执行通量守恒检查；最大误差约 1e-13 量级。此检查不代表连续空间已收敛。
- 零点能模型在 E=0.8、0.99 的关闭产物通道上透射为零。产物基态阈值从 8×8 基的 1.000694 改进到 10×10 基的 1.000083；解析阈值为 1。
- 隧穿全维 QD 热速率：dx≈0.15/能量步长0.04 加密为 dx=0.075/步长0.02 后，beta=2 从 3.77440e-4 变为 3.76674e-4；beta=4 从 5.40494e-6 变为 5.31167e-6。
- 隧穿 beta=2 的独立 RPMD 检查（32 beads，dt=0.01，1024 样本）得到 (3.09715 ± 0.10812)e-4；与原结果在采样误差内相容，但这不是完整的 bead 收敛扫描。
- 隧穿三维波包由 1024×24×24、dt=0.03 加密到 1536×32×32、dt=0.015，产物概率从 0.009457294 变为 0.009462762，相差约 0.058%。
- 共振峰位显著依赖 x 网格。dx=0.01875 的前两峰为 0.480510462、1.644449494；dx=0.009375 为 0.480522298、1.644517444。粗网格峰位不能称为高精度参考。
- 初次共振波包盒子存在边界占据，已弃用；报告采用扩展至 ±200 的重算数据，最终边界检查通过。
